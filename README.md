# Customer Shopping Behaviour Dashboard

## 📌 Project Overview
This project analyzes customer shopping behavior using Excel, SQL, and Power BI to uncover sales trends, customer segments, and purchasing patterns.

## 🛠 Tools & Technologies
- Excel (Data cleaning & analysis)
- SQL (Business queries)
- Power BI (Interactive dashboard)
- GitHub (Version control)

## 📊 Key Insights
- Top spending customers identified
- Product category-wise sales performance
- Customer age group buying patterns
- Preferred payment methods
- City-wise sales contribution
